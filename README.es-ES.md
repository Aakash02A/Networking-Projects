

# Portafolio de Proyectos de Redes 

Este repositorio contiene **proyectos prácticos** diseñados para ayudarte a dominar **Redes de Computadoras** mediante la creación de herramientas reales y la comprensión de cómo funciona cada protocolo a un nivel fundamental: desde la Capa 1 hasta la Capa 7 del Modelo OSI.

---

## 📚 Objetivos de Aprendizaje

- Dominar los modelos OSI y TCP/IP mediante su implementación
- Comprender cómo se mueven los paquetes, desde Ethernet hasta DNS
- Construir herramientas reales de redes para interiorizar los conceptos
- Familiarizarse con protocolos, puertos, encabezados, enrutamiento y conmutación

## 📈 ¿Por qué es importante este portafolio?

Comprender las redes es fundamental para la ciberseguridad, el hacking ético, DevOps y la infraestructura en la nube. Estos proyectos simulan escenarios del mundo real: desde el reconocimiento hasta la inspección de paquetes y la manipulación de tráfico, ofreciendo una forma práctica de interiorizar conceptos clave más allá de los libros de texto o cursos teóricos.

Este repositorio sirve tanto como herramienta de aprendizaje como demostración de tus habilidades prácticas en los fundamentos de las redes.
